# Claude Duet 宣传片 版本记录

英文、无声（只有画面和手写字幕）。一笔画 × 3D（Three.js）：浅色纸本，你的线墨黑、Claude 的线陶土色，真实 app 用 Simple Icons 官方字形，片尾是官方 Duet 图标。1920×1080，30 fps。

- v1《Two Lines》：你和 Claude 是两根线，一首二重奏。
- v2《The Ride》：你和 Claude 坐一辆两座的小过山车，车头的两支笔边走边画出脚下的轨道；一整天坐完升到高空，整条轨道就是 Duet 图标那一笔。
