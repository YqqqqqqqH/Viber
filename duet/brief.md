# duet · Claude Duet promo

## 1. 立项（2026-10-22）

- **题目**：Claude Duet 宣传片。Anthropic 于 2026-10-21 上线的 research preview（waitlist，先给美国 Pro / Max 用户）。
- **原材料**：官方文章 https://claude.com/resources/articles/claude-duet 。片里出现的事实只来自这篇：
  - 一个主动工作的 agent：看你连上的 app，挑出要注意的事，替你把事做完，**动手前先问你**。
  - 每天一份 morning brief；平时只在有事需要你时才来找你。
  - 能排会议，也能做 dashboard、预测、原型、web app。
  - 6,000+ connectors 和 plugins（Gmail、Slack、QuickBooks、Stripe、Shopify……）。
  - 发消息、付款、签文件、删除前，先把要做的事摆给你看，等你批准；证券交易、账户间转钱一律不做。
  - 跑在自己的虚拟机和浏览器里，你的电脑、手机不用开着；一个对话，打字或说话都行。
  - 敏感数据（卡号、证件号）有专门的分类器拦住，密码它看不到。
  - 官方原话："a partner you can trust"，"Put your attention where it matters most"。
- **语言**：全片英文，**不出现中文**。
- **要求**：干净，有动感、有张力。
- **时长 / 画幅**：30–60 s，16:9，1920×1080，30 fps。
- **声音**：无声，只做画面（用户 2026-10-22 选 Silent）。不写 mix.py，不登记拟音 EV。
- **品牌**：用户没有偏好，按默认来：「Claude Duet」用开源字体自己排字标，不用 Anthropic 官方 logo、星芒标和品牌字体。第三方 app 不画真 logo，用通用图标（信封、对话气泡、日历、发票）。
- **自带素材**：无。

## 2. 风格样片

- **测试镜头（招牌时刻）**：一阵消息风暴（发票、会议、未读、库存……）越堆越快 → Claude Duet 从里面挑出那一条要紧的（Dana 问周五能不能交货），把它变成一张批准卡「Reply to Dana?」，下面是 Approve 按钮 → 按下 Approve → 打勾 Sent。屏上字幕：**It asks before it acts.**
- 每个样片 4 秒，key 帧 2.8 s（卡片已落定、按钮就要被按下）。
- 候选（2026-10-22，`styles/candidates.json`）：
  1. `lemo/dark-keynote` 暗色科技发布：生成式消息风暴 → 冻结 → 选中那条展开成卡 → 光扫亮起。
  2. `lemo/swiss-motion` 瑞士动态排版：右页黑条按拍子卡入、左页巨大计数 → 刀切 → 唯一的橙条线性走出网格长成大块。
  3. `huashu/16_2026` 当代扁平插画（★★★）：咖啡店老板娘，消息泡越冒越多、紧张线 → 卡从手机里弹出 → 按下后松一口气。
  4. `grammar/y5_kinetic_type` 动态文字：「247 unread」砸入、事务词越来越密 → 穿越放大冲进橙色「Dana: Friday?」→「Reply to / Dana?」砸入 → 键帽按下。
  5. `house/three-3d` Three.js：象牙色空间里卡片漩涡 → 其余被甩进雾里 → Dana 那张翻面，背面就是批准卡。
  6. `lemo/one-line` 一笔画：一根线画信封、气泡、日历，缠成乱麻 → 停笔墨点 → 一笔抽出来画卡和按钮 → 唯一的橙色是那个勾。
- **用户的选择（2026-10-22）**：要浅色，不要深色；最喜欢 ⑥ 一笔画，「如果 3D 能支持更好」→ 定为 **⑥ `lemo/one-line` 的画法 × ⑤ `house/three-3d` 的空间**：
  墨线不离纸的规矩照旧（暖白纸、暖黑墨、强调色只用一次、手写字幕），但纸是 Three.js 里的一张真纸，线是有体积的墨线，能离开纸面飞进空中、投下影子；镜头可以压低、绕着转、带景深。笔本身不出现，只有笔的影子。
- 先做一个混合样片 `styles/7-one-line-3d/`（同一个测试时刻），确认 3D 版本成立，再在它上面出三个方案的预览。
- 共用引擎 `lib/ink3d.js`：纸、体积墨线（纸上扁、空中圆、投影）、手写字、跟笔镜头、笔影、手写字幕。每个预览页复制一份（lemo 服务器只给页面自己的文件夹）。

## 3. 三个方案（2026-10-22）

三个都是：暖白纸 #F8F6F1、暖黑墨 #1D1A17、全片唯一的强调色橙 #E2622E（只用在「批准」那一笔）、Caveat 手写字；16:9 · 1920×1080 · 30 fps；无声；Three.js 逐帧渲染。

### 方案 A：Untangle（稳妥）
**一句话**：一根线从一团乱麻里被拉直，然后一件件把事做完，到要你点头的地方停下来等。看完记住「乱 → 清 → 它会先问你」。
**规格**：约 46 秒
**画面概括**
1. 0–5s 微距跟着笔尖：线在纸上画出信封、对话气泡、日历、发票。"Every app wants a piece of you."
2. 5–11s 线离开纸面，在空中越缠越快、越抖越厉害；镜头压低绕过去，影子在纸上乱成一片。"All at once."
3. 11–14s 一切停住，那团线悬在空中。纸上写出 "Claude Duet"。
4. 14–20s 笔把那团线一把拉直、铺回纸上，接着画一张晨报：三行事，一行一个圈。"A morning brief. Only what matters."（预览就是这一镜）
5. 20–29s 同一根线变形：晨报第一行变成日历格子（"Thu 2:00 booked"）→ 格子长成柱状图 → 柱状图的轮廓变成网页线框。"Meetings. Dashboards. Prototypes."
6. 29–36s 画出批准卡 "Reply to Dana?"，线停在 Approve 旁边，笔影悬着不动；按下，橙色的勾。"It asks before it acts."
7. 36–41s 线依次画信封、硬币、签名三道小门，每道门前停一下。"Messages, payments, signatures: your call."
8. 41–46s 连续拉远：整张纸上所有画面原来是同一根线；最后一笔写出字标 "Claude Duet" 和 "Research preview · Join the waitlist"。
**难点**：拉直、变形这几处要做到前后两幅画共用同一段线。

### 方案 B：Two Lines（换画面组织：两根线二重奏）
**一句话**：「Duet」就是二重奏：一根粗线是你，一根细线是 Claude，一来一回地画，最后在空中绞成一股。看完记住「它跟你一起干活，最后一笔是你的」。
**规格**：约 40 秒
**画面概括**
1. 0–4s 俯视：纸的左下、右上两个角各落下一个笔尖（两片笔影），旁边写 "you" 和 "Claude"；中间写 "Claude Duet"。
2. 4–12s 左半边你的线狂写：信封、气泡、提醒，越写越乱；右半边 Claude 的线不慌不忙画一张清单 "Today: 3 things"。"It reads everything. It brings you three."
3. 12–20s 你的线想排个会，缠住了；Claude 的线伸过来接手，画出日历，格子落定 "Thu 2:00"。"It picks up where you leave off."
4. 20–27s 两根线往中间走；Claude 的线画出批准卡，停在按钮前；你的线过来补上最后一笔：橙色的勾。"It asks. You decide."
5. 27–35s 两根线一起离开纸面，绞成一股往上长，镜头压低绕着转，两道影子在纸上交错。"Two lines. One duet."（预览就是这一镜）
6. 35–40s 绞线落回纸面，铺成字标 "Claude Duet" + "Research preview"。
**难点**：两根线同时画、要分得清谁是谁（粗细 + 你的线更抖），一来一回的节奏要靠画面自己撑（无声）。

### 方案 C：One Day（换讲法：一天就是一根线，一个横移长镜头）
**一句话**：把一天画成一根横线，每个提醒是一座从纸上竖起来的尖峰；Claude Duet 沿着这一天走一遍，把尖峰压平，只在一个地方停下来问你。看完记住「它替你挡掉噪音」。
**规格**：约 46 秒
**画面概括**
1. 0–4s 低机位贴着纸面，左边写 "7:00"，线往右走。
2. 4–12s 线变成一天的波形：每个提醒一座尖峰，越往后越密越高，影子拉得很长，镜头横移像穿过一片山。"This is your day." / "Every ping, a spike."
3. 12–16s 镜头拉回左端，笔尖重新落下："Now, with Claude Duet."
4. 16–30s 笔沿着这一天再走一遍，走过的地方尖峰一座座倒平；经过整点写下办完的事：8:00 morning brief、10:00 meeting booked、13:00 forecast ready。"It handles the noise."（预览就是这一镜）
5. 30–36s 15:00 线停下，画出批准卡，等你按下：橙色的勾。"It asks before it acts."
6. 36–41s 18:00 线一直跑出纸的边缘："Your laptop's closed. It keeps going."（原文：跑在自己的虚拟机上，电脑、手机不用开着）
7. 41–46s 升到俯视：一整天平静的线和一个橙色的勾；字标 "Claude Duet" + "Research preview · Join the waitlist"。
**难点**：一个横移长镜头要一直有东西看；尖峰倒平的节奏要有张力。

预览：`previews/plan-a|b|c/`（key.jpg + preview.mp4），对比图 `previews/plans_sheet.jpg`，四格视频 `previews/plans_grid.mp4`。

**用户的选择（2026-10-23）**：选 **B《Two Lines》**，并要求：
1. Claude Duet 不只是「你 + Claude」，它把你和**更多 app** 连起来 → Claude 的线绕着一圈 app 一个个穿过去；片尾绞线时 app 的细线也绕进来。app 用通用手绘图标（用户选的），不出第三方名字和 logo；写 "6,000+ connectors"（原文）。
2. 片尾**用官方 Duet 图标**：用户确认可以用 Anthropic 的商标；已下载 `assets/claude-duet-icon.svg`（8 KB，只有 3 个 path）。图标本身就是一根有两个圈的墨线压在陶土色色块上，和本片的画法同源 → 结尾让绞线落回纸面、盘成这两个圈，陶土色在下面晕开，最后换成官方图标。强调色因此改用图标的陶土色 #D97757。
3. **转场要像 Apple 发布会**：一条连续的镜头曲线、速度连续；物体变成下一镜的物体；真要换场景就切在两边完全一样的那一帧上；快的甩镜带运动模糊；不叠化、不白闪、不黑场。

### 第二版分镜的改法
- **视野**：每画完一样东西就拉开、停一拍，整幅画完整在画面里；跟笔只做轻跟随。
- **干净**：去掉所有抖动、乱麻、交叉的连线。风暴改成：你的线绕着「you」一圈圈跑，越跑越快、越升越高，绕成一个整齐的线圈（紧张来自速度和高度，不靠乱）。Claude 的线画成一个轮子：绕外圈走，到每个 app 套一圈、拉一根辐条到中心再回来。卡片、晨报的边框从按钮/条目那一侧起笔，不再在框里贴边走第二道线。
- **真实 app**：7 个带厚度的 3D app 圆片（白面、品牌色侧边、官方字形），带红色未读角标：落下、跳动、数字往上涨；Claude 套住哪个，哪个的角标就消掉。晨报每一行前面是对应的 app 圆片，日历条旁边是 Google Calendar，原型旁边是 GitHub，回复卡上是 Gmail。
- **色彩**：Claude 的线改成陶土色（你的线仍是墨黑）；画完的形状会晕开一层淡淡的水彩色（晨报、星期四那一格、柱子、原型的色块、Approve 按钮）。绞线是一黑一陶土两股；落成图标时黑的那股变成图标那一笔，陶土那股渗进纸里晕成图标的色块。
- 结尾：7 个 app 圆片绕着绞线转，最后落成一排，在字标下面。

### v2 三个新方案（2026-10-23，预览在 previews/v2-a|b|c，对比图 previews/v2_plans_sheet.jpg）

**A《The Ride》—— 大图：Duet 图标本身**。你的黑线和 Claude 的陶土线是一条过山车轨道的两根轨，轨道的走向就是图标那一笔放大 9 倍。镜头就是乘客，全片一趟车、不切镜头：
起点（左边的尾巴）app 圆片砸在轨道上、角标往上涨，车慢慢爬坡（紧张）→ 第一个大回环立起来，镜头倒着穿过去，圈里的纸上写出晨报 → 谷底：一周，星期四亮起 → 第二个回环往上爬，柱状图像过山车的支架一根根长出来 → 第二个回环最高点：车倒挂着停住，批准卡就挂在那儿（It asks before it acts.），你勾下去 → 松开：全片最快的一段俯冲，原型和 GitHub 从旁边掠过 → 轨道躺平、镜头升到高空：一整天坐过的车原来画的是 Duet 图标，两根轨并成那一笔，陶土色在下面晕开，换成官方图标。
每一站都是图标里的一块：晨报在第一个圈里，dashboard 在第二个圈里，批准卡在第二个圈的顶上，一周在两个圈中间。

**B《Your Day, Mapped》—— 大图：一张手绘的「Your Tuesday」地图**。你的黑线画海岸线，Claude 的陶土虚线是路线；每个 app 是一处立体书地标，地图是折着的，每展开一折、一处地标就从纸上立起来：Gmail 灯塔、Calendar 群山（星期四插旗）、Docs 图书馆、Slack 港口、Stripe 桥（桥要你按 Approve 才放下来）、GitHub 森林、Shopify 集市。最后整张地图展开，镜头升起看全图，指南针就是 Duet 图标。好懂、可爱，张力最弱。

### v2 定下的做法（2026-10-23，用户选 A《The Ride》）

- **加了一辆车**：两座的小过山车，右座黑色棋子 = 你，左座陶土色棋子 = Claude（胶囊加圆球，不画脸和手脚：项目规矩不用代码画人）；车头底下就是两支笔，车边跑边画出自己脚下的轨（轨道永远只画到车头，前面是空纸——这就是紧张感）。只有两根线的时候看不出是过山车，有了车观众才有东西可跟。
- **镜头不用纯乘客视角**：试过镜头贴在两根轨中间，轨看起来像两根大水管、前面全是空纸，读不懂。改成跟拍：爬坡从侧下方往上看，坡顶从车后上方看，回环从正面低机位看车翻上去，俯冲从圈脚看车冲着镜头来，出口从侧后跟拍、站点在背景里掠过。跟拍的机位沿着轨道往后取（转弯时镜头跟着弯，不穿过轨道）。
- **每一站在大图里的位置**：起点一堆 app 在左尾巴下方；晨报在第一个圈里；一周和柱状图在两个圈下方；批准卡在第二个圈里；原型在出口那段旁边。俯拍揭晓时这些小画都还在图标里外，是「一整天」。
- **读字**：晨报和批准卡都有一段俯拍停住（各 ≥1.5 s），字幕避开它们的最后一行。
