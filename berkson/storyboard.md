# 《伯克森悖论》分镜表（约 192 秒 · C 夜曲 · 第二版）

> 第二版（2026-10-09，按用户意见改）：比喻从"门"换成"筛子"；章与章之间不再暗场，改成连续的换场；声音重做（见文末）。下表的字幕已更新；"屏上是什么"一列里的"门槛 / 门外"读作"筛网 / 被筛掉的"。

**一句话论点**：你看到的人和东西都过了一道门；只要这道门看的是"两样加起来够不够"，门里的这两样就会此消彼长。规律不在人身上，在筛子上。

**全片的形象**：一道门。每一章开头先画出这一章的门（医院、校门、巷子、婴儿秤、手机），一句话以后它缩成门槛牌子上的小图标，挂到那张表上。

**那把尺子**：一张 6×6 的表。36 张人物卡，每张一个线描的半身剪影和两颗骰子。列是金骰 1→6（从左到右），行是冰蓝骰 1→6（从下到上）。
表下面一行"每列的平均"：一个数字，加上一根画在该列平均高度上的水位条。门槛是一条玫红的阶梯线，挂一块牌子写规则。
从 01 到 05 这张表一直在，每章只换三处：两个轴的名字、牌子上的字和图标、卡片上的剪影（04 章换成襁褓里的婴儿）。

**同一个画面**：
- 序的六张约会卡，是 6×6 表门里的六张。尾声这六张卡回来，外面多了一个门框。
- 01 章门槛扫过以后的阶梯，在 02、03、04、05 章原样出现四次。
- 05 章末尾门外的人走回来，表回到 01 章门槛落下之前的样子（一排 3.5）。

**颜色**（全片不破例）：金 = 第一颗骰子（颜值 / 胆囊炎 / 数学 / 地段 / 抽烟 / 颜值）；冰蓝 = 第二颗骰子（人品 / 糖尿病 / 语文 / 味道 / 病因 / 内容）；
玫红 = 门槛，以及门造出来的"假规律"（变成阶梯的平均数、片名里的"悖论"）；白 = 人和东西本身；暗灰 = 门外的人。

**章节标**：00 序 PROLOGUE · 01 骰 DICE · 02 院 HOSPITAL · 03 门 DOORS · 04 秤 SCALE · 05 你 YOU

## 屏上的数怎么来的

- 6×6 表：两颗骰子的全部 36 种搭配，一种一个人。
- 每列平均人品：门槛落下前每列都是 (1+…+6)/6 = 3.5。门槛"加起来 ≥ 8"之后：颜值 1 → 没人；2 → {6} = 6；3 → {5,6} = 5.5；4 → {4,5,6} = 5；5 → {3…6} = 4.5；6 → {2…6} = 4。门里 15 人，门外 21 人。
- 第 21 镜的"约低一半"：二手来源转述的 Yerushalmy 1971 年数据有两组，147 对 72、218 对 114（每千人，低体重婴儿，非吸烟对吸烟），两组的比例都约为一半。屏上只写"约低一半"，十个图标里暗两个对暗一个是示意。
- 第 14 镜的"胆囊炎 × 糖尿病"：伯克森 1946 年论文里用的假想例子（据 IJE 2014 年重印本的评论和 Wikipedia）。

## 示意的地方（片尾一行小字写明）

骰子表是示意模型：真实的长相、人品、病情不是 1–6 的骰子；学校、巷子、博主三处没有用真实数据，是示意；第 21 镜的十个图标是比例示意。

## 第二版的改动（2026-10-09）

**1. 1:02 的声音卡顿。** 原因是"定理落地"那一下的 hush：和弦刚响 0.1 秒就被整段静音切断，2 秒后再淡回来，听起来像卡了。去掉 hush，改成一记低音 boom + 和弦自然衰减。

**2. 换场。** 不再用"暗一下"。全片一套换场语法：
- 序 → 片名：六张卡一边转一边收进正中，缩成一个光点，闪一下成片名。
- 片名 → 01：片名线上的光点升到正中，展开成第一张卡。
- 每章之间：筛子牌子像翻卡片一样翻到下一章的图标 → 镜头钻进牌子（对数缩放）→ 下一章的地方先以这个图标的大线稿长出来，细节再一笔笔画进去。
- 讲完一句：地方缩回牌子上的图标，镜头从图标里拉出来，回到那张表（轴名已经换好）。
- 04 → 05：表不动，轴名就地换（旧的往上淡出，新的落下），襁褓翻回人像，牌子上的手机图标长成一块屏幕把表框住。
- 05 → 尾声：筛子上留下的六张卡从屏幕里飞出来，排回开头那一排，下面画出一道筛网，被筛掉的人一张张掉到网下面。

**3. 比喻换成"筛子"。** 门里 / 门外不好懂；"过了线的留下，没过线的漏下去"更直观。牌子标题改成"筛子"，第 1 章的图标是一只圆筛；阶梯线外侧加了一排网眼；被筛掉的卡往下沉一截；第 15 镜的命名改成"筛过之后冒出来的假规律，叫伯克森悖论"；章节标 03 改成"处 EVERYWHERE"。

**4. 声音。** 项目自己的 `sound.py`（在引擎合成器上加事件，不改引擎），每个事件都对着画面：
卡片滑入 swipe / 落定 cardtap / 重排 shuffle / 发牌和归位 flick；平均数出来时弹 pluck，音高就是那个数（3.5 六声同音，6→4 一级级往下）；
骰子 dice（两次弹跳 + 落定前的晃动，和画面的弹跳同步）；线描 draw（铅笔）、筛网 draw（电流声）；被筛掉 sift（细沙漏下去）；
镜头推拉 whoosh；牌子翻面 flip；医院 monitor（心电监护的哔声）；校门 bell；巷子 street（人声 + 碗碟）；卷帘门 shutter；
