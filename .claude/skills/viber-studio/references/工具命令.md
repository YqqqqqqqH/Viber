# 工具命令（2026-10-14 在这台 Windows 机器上逐条跑通）

所有命令在 **Git Bash** 里跑，先把这几行设好。路径带空格（项目在 `TikTok Vibe` 里），一律加引号：

```sh
P="/c/Users/Yqh/Desktop/TikTok Vibe"            # 项目根目录
XILO="$P/.claude/skills/xilo-opus-video"
HUASHU="$P/.claude/skills/huashu-art-motion"
LIB=~/lemo-opuscar; export LIB
PY=$(python -c "import sys; print(sys.executable)")   # Windows 版 Python 3.13，uv 要用它
export PYTHONUTF8=1                                # Python 脚本按 UTF-8 读写，中文路径和中文输出才不出错
F="$P/<片>"                                       # 当前作品文件夹（绝对路径）
```

作品文件夹名用拼音或英文（`berkson`、`luanjiyuan`），和仓库现有的一致，也避开中文路径的编码问题。

- 风格目录给用户翻：`preview_start` 起 `.claude/launch.json` 里的 `style-catalog`（本地服务，端口 8765）。直接用 file:// 打开时，预览面板只给静态快照，图片出不来。
- 目录的素材：lemo 每张卡取 `$LIB/styleboard/img/<slug>_0.jpg`；huashu 配方用 `render.py --film gallery --solo <id> --stills 0.6 --no-counter` 渲；解说语法用 `assets/动画语法/<id>_总览.jpg`；本项目做过的画法从成片取帧（在脚本开头的 `HOUSE` 表里加）。
- `candidates.json` 里每个候选的 `key` 是招牌那一帧的秒数，`id` 要和目录里的一致，拼图才能配上「库里的样子」。
- 小样按 1280×720、30fps 渲；并排视频把每格缩到 960×540，单数个时补一格底色。

## lemo：渲染、事件、阅读检查、拼图、合成（都在 $LIB 下跑）

```sh
cd "$LIB"
node core/render/still.mjs "$F" 0.5 2 4.5 --out "$F/review/stills" --prefix s01_   # 静帧 → s01_0.5.jpg …
node core/render/still.mjs "$F" --range 0:60:2 --out "$F/review/scan"              # 每 2 秒一张
node core/render/video.mjs "$F/previews/plan-b" --fps 30 --out "$F/previews/plan-b.mp4"   # 小样
node core/render/readcheck.mjs "$F"                                                 # 屏上字停留够不够
.venv/bin/python core/render/sheet.py "$F/review/sheet.jpg" "$F"/review/stills/*.jpg --cols 3 --w 640
sh "$F/build.sh" --draft      # 960×540 草稿 → renders/draft.mp4
sh "$F/build.sh"              # 正式版 → renders/final.mp4（readcheck → events → 渲染 → mix.py → mux 到 -14 LUFS）
```

- 页面工具都收 `--size WxH`（默认 1920x1080）和 `--q 'k=v'`（页面里用 `location.search` 读）。
- `build.sh` 可用的环境变量：`FPS`（默认 30）、`WORKERS`（默认 3）、`GRAIN`（mux 时加胶片颗粒，默认 0）。
- `sheet.py` 把**文件名**印在每格上，分镜图的文件名写成 `s03_push_4s.jpg`。它用 PIL 默认字体，中文文件名会印成方块，所以只用英文和数字。
- 拟音函数在 `$LIB/core/audio/sfx.py`：`click clack crash whoosh creak thump step ding pop quindar rumble ignite roar heartbeat radio`。都返回 48 kHz 单声道，用 `sfx.add(buf, x, at, gain, pan)` 放进立体声轨。

## Windows 上踩过的坑

- Git Bash 里的 `python3` 是 MSYS2 的 Python，uv 不认（报 `mingw_x86_64_ucrt_gnu`）。用 `python` 或 `$PY`。`uv venv --python 3.12` 会报 managed python 链接坏了，所以要直接给 `$PY`。
- lemo 的 `setup.sh` 要在**项目根目录**跑。在 `~/lemo-opuscar` 里面跑时，`git rev-parse` 返回 `C:/…`，脚本会拼出一个错误的路径。
- lemo 处处写死 `.venv/bin/python`，Windows 的 venv 在 `.venv/Scripts`。已经用目录联接 `.venv/bin → Scripts` 解决，在 Git Bash 里 `"$LIB/.venv/bin/python"` 能用。
- `setup.sh deps voice|music` 到 `uv pip install --python .venv/bin/python` 这一步会失败（uv 是原生程序，不认这个路径）。要加这两组依赖时手动装，再写上标记文件：
  ```sh
  cd "$LIB" && uv pip install --python .venv/Scripts/python.exe -r requirements-music.txt
  sig() { cat "$@" | cksum | cut -d' ' -f1; }; echo "$(sig requirements-music.txt)-$(.venv/bin/python -V 2>&1 | cut -d. -f1,2)" > .venv/.lemo-music
  ```
- `sfx.compress` 只能处理单声道，而且是逐采样的 Python 循环，长片很慢，整轨只用 `sfx.limit`。
- `mux.sh` 两遍 loudnorm。几秒长、只有一两个音效的测试片会偏离 -14 LUFS 并报警告，正式片不会。
- xilo 的脚本在没开 UTF-8 模式时，遇到中文路径就崩（ffprobe 的输出按 GBK 解码失败）。所以要 `export PYTHONUTF8=1`。
- xilo 的 `render.py` 用 file:// 打开页面，加载不了 `/core/lib.js` 和 ES 模块，本工作流不用它。
- ffmpeg 的 concat 列表用相对路径（`file '_h0.mp4'`）；`drawtext` 在这台机器上会段错误，拼图不要加字；按秒取帧用渲染器，不用 `ffmpeg -ss`（会早一帧）。
- 存版本时**复制**成片，不用硬链接：ffmpeg 会原地截断输出文件。

## Three.js 片子踩过的坑（2026-10-23，duet）

- **雾要跟镜头距离走**：ink3d 的 `stage()` 默认雾 16–36 单位；远景镜头离纸 20–25 单位时，整片被雾冲淡 30–45%（线发灰、颜色发白、官方图标偏粉）。远景多的片子传 `fogNear: 32, fogFar: 75`，天空色 `sky` 设成打过光的纸色（低机位时地平线才不出一条亮带）。
- **`toneMapped: false` 在 EffectComposer 里不起作用**：色调映射是 OutputPass 对整帧做的，材质上的开关被忽略。要原色就别加雾、少打光，必要时预先补偿颜色。
- **圆柱顶面的贴图是横的**：`CylinderGeometry` 顶面的 UV 转了 90°，`rotateX(π/2)` 立起来以后再给贴图 `center=(.5,.5)`、`rotation=π/2`。
- **透明的字和水彩谁盖谁靠 `renderOrder`**：都不写深度时按物体中心远近排序，大块水彩会盖到字上让字发灰；水彩 5、字 10。
- **换场景切在一模一样的帧上**：纸纹按 34×20 单位周期平铺，A、B 两个落点 x 正好差 3400 设计像素，镜头潜到只看得见白纸的那一帧换过去，两帧逐像素差 0.06。落点要贴着一根线（60px 左右），不然换场景前后会有 0.3 秒以上的纯白纸，huashu 门禁报红。
- **亮度逐帧量**：`ffmpeg -i final.mp4 -vf "scale=240:-1,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=yavg.txt" -f null -`，再看 1 秒内最大变化和单帧最大跳变。
- **在 Git Bash 里用 heredoc 喂长 Python 补丁容易因为引号出错**（`unexpected EOF`），改一大批代码时把补丁写成 scratchpad 里的 .py 文件再跑。
